# PAIOS Platform

A Personal AI Operating System.

## Quick Start

```bash
pip install -e .
python -m paios_installer init
```

## Architecture

| Layer | Description |
|-------|-------------|
| 00_CAPTURE | Information entry point |
| 10_WORK | Active workspace |
| 20_KNOWLEDGE | Formal knowledge base |
| 30_SYSTEM | System kernel |
| 40_AUTOMATION | AI automation engine |
| 50_DATA | Data infrastructure |
| 90_ARCHIVE | Historical archive |
