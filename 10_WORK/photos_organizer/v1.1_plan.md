# PAIOS 照片分类 V1.1 改进计划
# 版本: draft
# 日期: 2026-07-08
# 状态: 待第一次全量审查后执行

## 核心架构变更

### 1. Classification Policy 裁决层
当前流程: 图片 → CLIP/GLM(候选) → 最终分类
V1.1流程: 图片 → CLIP/GLM(候选) → Policy(裁决) → 最终分类

Policy 文件: 30_SYSTEM/photo/classification_policy.yaml
优先级: 路径启发式 > Policy 规则 > 标签映射 > AI 建议

### 2. CLIP Prompt 优化
当前: categories = ["人物", "工作", "旅行", ...]  (单字标签)
V1.1: categories = ["一张有人物的照片...", "工作会议、办公培训...", ...] (描述性文本)

根据 classification_policy.yaml 的 clip_prompts 字段动态生成。

### 3. corrections 表字段级记录
旧 schema: 一行记录一次完整纠偏 (wrong_category, correct_category, ...)
新 schema: 每个字段单独记录 (field, old_value, new_value, reason, pattern_id)

关键新增: pattern_id — 同一原因的纠偏归为一组，这才是模式提取的基础

### 4. 错误模式 vs 单张纠偏
旧思维: "这张错了"
新思维: "为什么100张都错？" → pattern_id 归组 → 提取 Classification Policy 规则

## V1.1 改进步骤

### Step 1: 全量审查 (v1.0-review)
- 工具: 05_review_report.py (405张智能抽样)
- 人工翻看审查报告，记录纠偏
- 重点: 低置信度、07_ToReview、"其他"类

### Step 2: 纠偏记录
- 工具: 06_correct.py 或自然语言对话
- 每条纠偏必须带 reason（"公司聚餐不是工作会议"）
- 同 reason 归为同一 pattern_id

### Step 3: 模式提取
- 工具: 07_analyze_corrections.py
- 输出: 混淆矩阵、词表缺失、规则冲突、阈值问题
- 关键: 按 pattern_id 归组统计，不是按 photo_id

### Step 4: 更新 Classification Policy
- 从模式提取结果更新 30_SYSTEM/photo/classification_policy.yaml
- 版本: v1.0-draft → v1.1
- 重点填充 edge_cases 和 include/exclude 规则

### Step 5: CLIP Prompt 替换
- 04_classify.py 的 PRIMARY_CATEGORIES 从单字改为描述性文本
- 参考 classification_policy.yaml 的 clip_prompts 字段

### Step 6: Policy 裁决层集成
- 04_classify.py 新增函数: apply_policy_rule(category, source, tags, policy)
- 裁决修正时记录 classifier=policy_override, classifier_version=policy-v1.1

### Step 7: 局部重跑
- 只重跑: corrections 涉及的照片 + 低置信度照片
- 对比 v1.0 vs v1.1 分类差异
- 差异写入新的 photo_versions (version=2)

### Step 8: 验证冻结
- "其他"类占比 < 5%
- 低置信度照片比例下降
- 规则稳定 → 冻结 classification_policy.yaml

## 纠偏示例

### 单张纠偏（对话）
告诉 Buddy:
  "photo_id=1 这张是朋友聚会，不是工作会议，应该是 01_Personal"

Buddy 执行:
  corrections 表写入:
    field=source, old_value=02_Work, new_value=01_Personal
    field=category, old_value=人物, new_value=聚会  (如果需要)
    reason="朋友聚会不是工作会议"
    pattern_id="公司聚餐归Personal"

### 批量模式纠偏
告诉 Buddy:
  "02_Work 里所有公司聚餐的照片都应该是 01_Personal，因为员工私人活动即使地点在公司也归 Personal"

Buddy 执行:
  批量纠正所有匹配的照片
  每条 corrections: reason="员工私人活动归Personal", pattern_id="公司聚餐归Personal"
  pattern_id 相同 → 后续模式提取时归为一组

### 规则纠偏（词表扩展）
告诉 Buddy:
  "饮料和甜点也应该归美食类"

Buddy 执行:
  vocabulary 表添加: object:饮料, object:甜点 → mapping=01_Personal
  classification_policy.yaml 美食.include 扩充

## 关键原则

1. 不改文件，只改元数据 (Immutable Original Principle)
2. 不纠偏单张，找错误模式 (Pattern > Instance)
3. reason 是训练数据，不是备注 (Reason is Training Data)
4. Policy 是最终裁决，AI 只是候选 (Policy > AI)
5. 纠偏数据 > CLIP准确率 (Personal Semantic Correction > Model Accuracy)
