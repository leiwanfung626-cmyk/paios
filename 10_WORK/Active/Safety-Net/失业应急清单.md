# 失业应急清单

> 这不是规划文档，是**操作手册**。失业当天按顺序执行。
> 平时不动它，但每月底检查一次政策是否有变。

## 一、失业金（第一收入替代）

### 基本事实

| 项 | 内容 |
|----|------|
| 江门标准 | **1665元/月**（最低工资1850的90%） |
| 最长期限 | **24个月**（缴费10年以上） |
| 发放时间 | 业务办结次月15日前，之后每月15日到社保卡 |
| 发放方式 | 打入社保卡金融账户 |

### 领取条件（需同时满足）

1. 失业前失业保险费累计缴满1年（或有剩余领取期限）
2. **非因本人意愿**中断就业（项目终止/公司裁撤符合，主动辞职不符合）
3. 已办理失业登记，并有求职要求

### 缴费年限对应期限

| 累计缴费 | 领取期限 |
|---------|---------|
| 1-4年 | 每满1年领1个月 |
| 4年以上 | 超过4年部分，每满0.5年增加1个月 |
| 上限 | 24个月 |

### 申领流程（失业当天/次日执行）

**第1步：办理失业登记**（必须先做，否则领不了失业金）
- 线上：微信"粤省事"小程序 → 社保就业 → 失业登记
- 线下：带身份证/社保卡到鹤山就业服务中心/公共就业服务机构/一门式服务中心

**第2步：申领失业金**
- 线上：粤省事小程序 / 广东人社APP / 广东省人社网上服务平台
- 线下：带以下材料到社保经办机构
  - 社保卡或身份证
  - 终止/解除劳动关系材料（公司出的）

**第3步：每月失业签到**
- 粤省事小程序完成，不签到可能停发

### 关键提醒

- **"非因本人意愿"是核心**。如果是公司项目终止、合同到期不续签，符合。如果是你自己主动辞职，不符合。务必让公司出具"解除/终止劳动关系证明"时写明是公司原因。
- **不要拖**。失业后尽早办，越早办越早到账。
- 社保卡要激活金融功能（去发卡银行激活），否则钱打不进来。

## 二、失业期间医保（不用自己缴，自动衔接）

### 基本事实

| 项 | 内容 |
|----|------|
| 医保类型 | 职工基本医疗保险 |
| 缴费方式 | **失业保险基金代缴，个人不缴费** |
| 待遇 | 正常享受医保报销（门诊/住院） |
| 依据 | 《广东省失业保险条例》第二十条 |

### 你需要做的

**什么都不用做。** 领取失业金期间，医保由失业保险基金自动代缴，你的医保待遇不会断。

### 注意事项

- 失业金领完（最长24个月）后，医保需要自己接续（转灵活就业医保或城乡居民医保）
- 失业期间看病，正常刷医保卡即可

## 三、失业期间养老保险（要自己续，但可以选择不续）

### 基本事实

| 项 | 内容 |
|----|------|
| 失业期间养老险 | **不会自动缴**，缴费年限暂停累计 |
| 续缴方式 | 以灵活就业人员身份自己缴 |
| 缴费比例 | 20%（12%统筹 + 8%个人账户） |
| 广东缴费档次 | 60%/70%/80%/90%/100%/150%/200%/250%/300% 共9档 |
| 最低档月缴（估算） | 约1000-1100元/月（按缴费基数下限×20%） |

### 决策建议

**领取失业金期间，养老保险可以先不续。** 理由：

1. 失业金1665/月，如果再拿出1000+交养老险，月可用现金只剩600，生存压力过大
2. 养老险累计缴费满15年即可领退休金，中断几年不影响最终领取资格（影响的是金额）
3. 优先保当前生存，养老是60岁以后的事

**如果将来收入稳定了再续。** 续缴渠道：
- 微信："社保云缴费"小程序
- 支付宝：市民中心 → 社保 → 灵活就业社会保险
- 粤税通APP
- 广东税务公众号

## 四、就业困难人员认定（失业满1年后申请）

### 基本事实

| 项 | 内容 |
|----|------|
| 男性大龄失业人员年龄门槛 | **50周岁** |
| 你的情况 | 47岁，不符合"大龄"类别 |
| 但符合另一条 | **"连续失业1年以上人员"** |
| 认定后可享 | 公益性岗位安置 / 社保补贴 / 就业帮扶 |

### 时间线

1. 失业当天：办失业登记
2. 失业满1年：申请"就业困难人员"认定（按"连续失业1年以上"类别）
3. 认定后：公共就业服务机构提供Ⅰ→Ⅱ→Ⅲ级帮扶，符合条件可安置公益性岗位

### 认定流程

- 向户籍地（常住地）街道/社区公共就业服务机构提出申请
- 材料：身份证或社保卡
- 流程：申请 → 初审公示（5个工作日+3个工作日公示）→ 审核认定（10个工作日内）

### 公益性岗位

认定2个月后仍未就业，通过市场渠道确实难就业的，可走Ⅲ级兜底帮扶，公益性岗位安置。这是路径A（兜底保稳）的落地点。

## 五、应急清单执行顺序（失业当天）

```
□ 1. 拿到公司出具的《解除/终止劳动关系证明》（确认写明非个人原因）
□ 2. 粤省事小程序办理失业登记
□ 3. 粤省事小程序申领失业金
□ 4. 确认社保卡金融功能已激活（去银行激活）
□ 5. 设置每月失业签到提醒
□ 6. 盘点现金（2万），重算支撑月数
□ 7. 检查医保是否正常（失业基金代缴，看病刷卡测试）
□ 8. 养老险：暂不续（决策已定，见第三节）
□ 9. 更新本清单：记录实际失业日期、失业金到账日期
```

## 六、每月例行检查（每月底花10分钟）

- [ ] 失业签到是否完成
- [ ] 失业金是否按时到账（每月15日前）
- [ ] 医保是否正常（刷一次卡确认）
- [ ] 政策是否有变化（粤省事/江门社保公众号）
- [ ] 现金余额更新
