## 三、核心循环：Capture → Classify → Store

这是每天发生的事，也是本系统最有价值的部分：

```
① 你投喂   学的内容 / 错题 / 疑问  ──→  00_CAPTURE/Inbox.md
                ↓
② 我捕获   读你的输入，判断：属于哪科？哪个章节？是不是错题？
                ↓
③ 我分类   新知识点 → 写进对应 Reference 新章节
            错题     → 写进该科「错题」章节，并打「薄弱点」标签
            疑问     → 我先答，再把问答记成「使用经验」
                ↓
④ 你复习   晚上拿着我整理好的东西复习 / 继续提问
                ↓
⑤ 我进化   同类错题 ≥3 → 提炼成 Method；跨学科联系 → 写成 Concept
```

**你只负责 ① 和 ④，剩下的 ②③⑤ 都是我的活。** 这正是关键决策 KY-DEC-003 定的：父亲/复习者负责投喂，PAIOS 负责处理。

## 五、从今天起，每天怎么操作（每日清单）

把下面当成每日打卡表，能完成 60% 就很棒，关键是**别断**：

### 晨间 / 学完即投喂
- [ ] **英语（每日固定）**
  - [ ] 长难句 2–3 句 → 丢给我拆解（优先！）
  - [ ] 阅读 2 篇错题 → 丢给我分析错误类型
  - [ ] 单词第二轮进度 → 一句话报给我
- [ ] **数学（强化阶段）**
  - [ ] 1000 题当日错题 → 题号 + 你的错误思路 + 正确关键点，全丢给我
- [ ] **统计学**
  - [ ] 当日章节笔记 / 概念 → 丢给我建框架
- [ ] **政治（每天 30 分钟）**
  - [ ] 马原视频/章节 1 个关键概念 → 丢给我入库

### 晚间
- [ ] 把当天没搞懂的 1 个问题问我 → 我基于当天知识答，并记成经验
- [ ] （可选）看我当晚整理的当日小结

### 睡前（我来做）
- [ ] 我把今日条目在 `Inbox.md` 标记 `[x]`，写入 `Today.md`，更新对应 Reference

> 📌 **最简启动**：哪怕今天只做一件事——把**一道数学错题**或**一句长难句**发给我，就算正式开始了。决策 KY-DEC-003 的要求就是「每天至少 1 条」。

**每个库都预留了 4 个「会自己长大」的区块：**
- `## 错题` —— 你每道错题进来都追加一行（题号 / 错误类型 / 根因）

**主题层过滤规则**（很重要，避免库变垃圾场）：同一科持续更新**同一个文件**，不每道题建新文件；同一具体主题 2 周内出现 ≥2 次才考虑提炼 Method/Concept。

## 十、常见疑问（FAQ）

**Q：我在手机上学的，怎么投喂？**
A：两种路——① 直接在**这台电脑**的对话里发（最顺）；② 手机微信先把内容发给父亲，父亲粘贴进这里。图片/文字都能发。

**Q：错题拍得歪/手写，你能认吗？**
A：能读图，但拍清楚点识别更准。实在不行，把「哪章哪题 + 你错在哪」打字告诉我，效果一样。

**Q：政治现在（7 月）开始晚不晚？**
A：不晚，决策 KY-DEC-002 已定，每天 30 分钟搭框架，9 月再刷题完全来得及。别因为「听说别人早开始了」就焦虑。

**Q：那 3 份 onboarding PDF 找不到怎么办？**
A：不用找。它们不在这台电脑里，本手册就是文字版替代，且该动手的（建库、投喂）已经帮你起好了头。

**Q：我断更几天会怎样？**
A：不会清零，库里已有的都在。只是我的「主动预警」需要连续数据，断更越久，下次分析越要靠你多喂几天补回来。所以尽量别断。

**Q：什么时候 PAIOS 会主动告诉我「该学什么」？**
A：模拟推演里是 Day 25 起开始预警薄弱点，Day 65 起能规划每日日程。真实节奏取决于你投喂的密度和质量——喂得越实，我越聪明。
