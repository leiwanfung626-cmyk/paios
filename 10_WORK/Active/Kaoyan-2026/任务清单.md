# 考研2026 — 任务清单

## 7月（Day 1-31）— 基础巩固期

### 英语（每日固定）
- [ ] 长难句拆解：每天2-3句，丢给 PAIOS 记录拆解方法
- [ ] 阅读理解：每天2篇，错题丢给 PAIOS 分析错误类型
- [ ] 单词：第二轮继续，进度记录给 PAIOS
- [ ] 作文：暂不启动，先攻长难句和阅读

### 数学（强化阶段）
- [ ] 1000题继续刷，每道错题丢给 PAIOS
- [ ] PAIOS 按知识点分类错题
- [ ] 周末：PAIOS 汇总本周错题分布，标记薄弱点
- [ ] 目标：7月底完成1000题，错题全部入库

### 统计学
- [ ] 将前2个月复习内容结构化录入 PAIOS
- [ ] 建立专业课 Reference 框架
- [ ] 开始做课后习题/真题，错题入 PAIOS

### 政治（起步）
- [ ] 马原开始，每天30分钟
- [ ] 看1个视频/章节，关键概念丢给 PAIOS
- [ ] PAIOS 建立政治 Reference 框架

## 8月（Day 32-62）— 强化深化期

### 英语
- [ ] 长难句：进入真题长难句，每天3句
- [ ] 阅读：加量到每天3-4篇
- [ ] 作文：开始每周1篇，PAIOS 对比范文标注差距
- [ ] 第一次英语模考（月底）

### 数学
- [ ] 1000题完成，开始真题
- [ ] PAIOS 分析错题模式：哪个知识点错误率最高
- [ ] 第一次数学模考（月底）

### 统计学
- [ ] 真题开始
- [ ] PAIOS 建立概率论↔统计推断跨学科连接

### 政治
- [ ] 马原完成，进入毛中特
- [ ] 开始做1000题选择题

## 9月（Day 63-93）— 真题阶段

- [ ] 全科进入真题
- [ ] 第一次全科模考
- [ ] PAIOS 开始主动分析薄弱点（需 Day 50+ 数据积累）
- [ ] 英语作文：每周2篇
- [ ] 政治：1000题 + 史纲

## 10月（Day 94-124）— 二刷+模考

- [ ] 真题二刷，对比一刷错误率
- [ ] 模考2-3次
- [ ] PAIOS 开始规划每日复习日程（需 Day 80+ 数据积累）
- [ ] 政治大题框架开始

## 11月（Day 125-155）— 冲刺期

- [ ] 政治大题背诵
- [ ] 全科模考保持手感
- [ ] PAIOS 全科大管家模式
- [ ] 查漏补缺，只攻薄弱点

## 12月（Day 156-172）— 考前

- [ ] 不学新东西
- [ ] 翻看 PAIOS 知识目录，确认"都知道"
- [ ] 看自己提炼的 Method 卡片
- [ ] 模考保持手感
- [ ] 心态管理

## PAIOS 每日任务（父亲侧）

- [ ] 每天接收儿子的学习输入（笔记/错题/疑问）
- [ ] Capture → Classify → Store
- [ ] 晚上回答儿子的提问
- [ ] 记录问答到使用经验

## PAIOS 每周任务

- [ ] 汇总各科错题分布
- [ ] 标记薄弱点变化
- [ ] 更新各科 Reference 章节
- [ ] 输出周报：本周进步/退步/下周建议

## PAIOS  onboarding 任务（根据儿子反馈动态调整）

- [ ] 等待儿子看完第一份材料后的反馈
- [ ] 如第一份也被搁置，准备"5分钟快速了解"版本
- [ ] 确认儿子是否愿意开始试用 PAIOS（从任一科目任一具体问题开始）
- [ ] 确认首选投喂方式：拍照 / 语音 / 文字 / 直接发文件
- [ ] 记录 onboarding 全过程作为第一个用户体验案例
