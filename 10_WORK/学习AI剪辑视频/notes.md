1. [ ] 写第 1 个 prompt：简单场景描述 → 生成 5s 视频

3. [ ] 尝试 图生视频：用一张图 + prompt 生成

### 阶段 2：进阶能力
1. [ ] 运镜控制：Camera Motion
2. [ ] 风格迁移：写实/动漫/电影感
3. [ ] 多段拼接：把多个 AI 片段合成完整视频
4. [ ] 配套剪辑：剪映做后期（字幕、转场、配音）

2. [ ] 写分镜稿
3. [ ] 逐段生成
4. [ ] 剪辑合成
