# Codex CLI 使用技巧（Jason Liu 教程）

> **来源**：抖音视频（OpenAI 官方教程｜如何把你的 Codex 用到极致）

## 概述

Jason Liu 的教程分 10 个小节，涵盖 Codex 的独占功能、最佳实践等。视频将其拆解为 **4 个层次**：

---

## 第一层：两个使用习惯的改变

### 1. 持久对话（Persistent Conversation）

- ❌ 旧习惯：像搜索引擎一样用完就走，每个问题新建对话
- ✅ 新习惯：为长期任务建立**固定对话**，同类任务始终在一个对话里进行
- Codex 优势：能主动记忆、压缩上下文，即使对话很长仍能记住关键信息
- 好处：提升效率、节省 token、减少重新探索项目的时间

### 2. 语音输入（Voice Input）

- Agent 时代「提示词工程」已被「上下文工程」「Harness 工程」「工作流循环」取代
- AI 变得更聪明，精雕细琢提示词不再重要
- 重点：**最大限度表达你的想法**
- 用语音输入把未整理好的想法直接倒给 Codex → Codex 梳理补充 → 几轮沟通收窄需求

---

## 第二层：工作中的更好互动

### 1. 侧边栏（Sidebar）

- 在 Codex 中直接看到当前项目文件 + 最新产出结果
- 不需导出文件 → 打开软件 → 复制内容 → 告诉 AI 改哪里
- 直接看 → 直接标注 → 直接让 Codex 改
- 将「审查」和「修改」两个环节连接起来

### 2. 任务干预（Task Intervention）

- 观察 Codex 执行过程，发现跑偏即时微调
- 例：「这个地方先别改」「这句文案不是我要的意思」「先把布局问题解决掉」

### 3. 任务排队（Task Queue）

- 提前安排下一步：做完 A 接着做 B
- 例：页面改完 → 跑单元测试 → 整理说明文档
- Codex 不再像问答框，更像坐在旁边的同事

---

## 第三层：让 Codex 自己干活（自动化）

### 1. 自动化（Automation）

- 在设定时间自动执行重复性任务
- 适用场景：检查消息、写日报、搜集每日资讯
- 流程：设定固定对话 → 沟通好需求 → Codex 定时执行 → 你只做最终审核

### 2. Goose 模式

- 适合有明确交付标准的任务
- 告诉 Codex 最终目标 → 它自主推进 → 过程中验证结果 → 产出符合要求
- 例：为现有项目新增功能、排查 bug

### 3. 手机端（ChatGPT APP）

- 在 ChatGPT 手机 APP 上接入运行 Codex 的电脑/远程环境
- 可查看任务状态、审批命令、变更方向、开新任务
- 不一定要坐在电脑前

---

## 第四层：持久记忆

- Codex 虽有自动记忆，但最稳妥的方式是**以文本保存项目信息**
- 建立文件夹，让 Codex 编写：
  - 项目情况
  - 代办事项
  - 工作日志
- 工作中实时更新 → Codex 记更牢 → 团队信息共享

---

## 总结：让 Codex 用到极致 = 工作系统问题

1. 固定对话 + 语音输入 → 改变使用习惯
2. 侧边栏 + 任务干预 + 任务排队 → 让 Codex 参与协作
3. 自动化 + Goose + 手机端 → 不盯着也能推进
4. 关键经验写进文件 → 形成共享记忆 → 长期可靠的工作伙伴

---

## 额外技巧：白嫖 Codex 额度

- 每个额度周期结束前，将未完成任务一股脑交给 Codex
- Codex 会自己规划，在一个对话轮次中即使额度用尽仍持续工作直到完成
- 规划得当可白嫖翻倍甚至更多额度
