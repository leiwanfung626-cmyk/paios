## 核心内容（经 Web 独立验证）

### 1. 数据科学 是真实的研究生招生专业

- 掌上考研（kaoyan.cn）有专门的「数据科学」专业页（major/22414），提供**开设院校名单、招生人数、分数线**。
- 示例（该页披露）：**武汉大学 · 前沿交叉学科研究院 · 数据科学**，2025 招生 113 人（全日制），专业线 305。
- 专业代码归属：数据科学多落在 **交叉学科 / 理学(07) 邻近统计学(0714)** 范畴；具体代码各校不同，需逐校查研招网（⚠️ 未精确核实统一代码）。
- **对项目的意义**：数据科学≠"计算机擦边"，是有完整招生目录的独立方向，BIT 目标专业成立。

### 2. 北京理工大学（BIT）数据科学考研

- BIT 确有数据科学硕士招生：2025 年 BIT 数据科学「不区分研究方向」（路灯考研招生专业介绍）。
- BIT 已设**人工智能学院**（2026 硕士招生专业目录已单列），数据科学可能挂靠数学与统计学院 / 人工智能学院 / 计算机相关学院（⚠️ 具体归属需查 BIT 研招网当年目录）。
- 本项目已知 BIT 数据科学考试科目：**英语二 / 数学三 / 统计学 / 政治**（见 `10_WORK/Active/Kaoyan-2026/当前状态.md`）。
- **行动项**：查 BIT 研招网 2027 目录，确认数据科学是否**扩招 / 新增方向 / 初试科目改革**（27考研 改革窗口期）。

### 3. 27考研 新增硕士点密集 —— 直接支持视频"有新增可能很大"

- 多省份已公示拟增列硕士学位授予点（如浙江：1 个一级学科 + 6 个专业学位点），审核通过后纳入 27考研 招生目录（路灯考研，2026-07-06）。
- **首年招生特征**：竞争小、信息差大、无参考教材、考生观望 → 一志愿上线率低、过线录取概率高（"低分上岸"机会）。
- **对项目的意义**：这是 27考研 择校的实打实政策利好。BIT 之外，可把"新增数据科学/大数据硕士点"院校纳入**备选池**，作为风险对冲。

### 4. 院校择校梯队（新东方，数据科学与大数据技术）

| 梯队 | 代表院校 | 特点 |
|------|---------|------|
| 顶尖 985 | 清华、北大、浙大 | 学术/资源顶尖，竞争最激烈 |
| 特色强校 | 哈工大、北邮、电子科大 | 行业优势强（航天/通信/算法），方向聚焦 |
| 高性价比双非 | 南京邮电、杭州电子、重庆邮电 | 竞争相对小、行业认可高、地域就业好 |

> 数据科学强校与 BIT（985、理工强、北京区位）定位接近"特色强校/中坚985"段，择校时可横向对比。

### 5. 国家线归属（⚠️ 待核实）

- 数据科学一般归属 **理学(07) / 工学(08) / 交叉学科**，国家线随门类浮动。
- 2026 年国家线具体数值未在本次抽取中精确抓取，**务必到 `yz.chsi.com.cn` 查当年理学/工学国家线**再下结论。
