## 三、通用操作流程（四步法）

### 第一步：明确需求

动手前先回答四个问题：

1. **演示主题**：这份PPT讲什么？核心信息是什么？
2. **目标受众**：给谁看？他们懂多少背景知识？
3. **页数和时长**：需要多少页？演示多长时间？（经验值：每页约2分钟）
4. **视觉风格**：商务正式？学术严谨？创意活泼？

### 第二步：选对工具

参考上面的决策逻辑，选一个工具。不要同时试多个——浪费时间。

**选择原则：**
- 中文内容为主 → 国内工具
- 需要原生PPTX编辑 → WPS AI 或 Copilot
- 设计感是第一优先级 → Gamma
- 有现成文档要转 → 支持文档上传的工具

### 第三步：写好提示词（最关键）

#### 提示词公式

```
[主题] + [受众] + [页数] + [风格] + [特殊要求]
```

#### 提示词模板

**模板1：主题生成型（从零开始）**
```
请帮我制作一份关于「[主题]」的PPT。

- 受众：[技术团队/管理层/客户/学生]
- 页数：约[10]页
- 风格：[蓝色商务风/绿色清新风/暗色科技风]
- 每页要求：[3-4个要点，配数据图表]
- 特别说明：[需要包含XXX章节 / 重点突出XXX]
```

**模板2：文档转换型（有现成内容）**
```
请基于以下文档内容生成PPT：

[粘贴文档内容 / 上传文件]

要求：
- 保留原文核心数据和结论
- 分为[5]个章节，约[15]页
- 风格：[商务简约]
- 封面包含：[标题、副标题、日期]
```

**模板3：大纲优化型（有大纲）**
```
我的PPT大纲如下：
1. [章节1]
2. [章节2]
...

请基于这个大纲生成完整PPT，每页展开为3-4个要点，风格[XX风]。
```

#### 提示词技巧

| 技巧 | 差的写法 | 好的写法 |
|------|---------|---------|
| 具体化主题 | "做一份营销PPT" | "做一份Q3季度数字营销复盘PPT，包含投放数据、ROI分析和下季度策略" |
| 指定受众 | "做个汇报" | "做一份给技术团队的架构汇报，受众有后端开发经验" |
| 限定页数 | "做几页" | "做12页，封面1页+目录1页+正文9页+结尾1页" |
| 给素材 | 不给素材 | 上传Word文档/粘贴大纲，让AI基于真实内容生成 |
| 指定风格 | "好看一点" | "深蓝色商务风，简洁排版，少文字多图表" |

### 第四步：精修打磨

AI生成的初稿一定需要人工调整，重点检查：

1. **内容准确性**：AI会编造数据、引用、人名——必须核实
2. **逻辑结构**：章节顺序是否合理？有没有重复或遗漏？
3. **配图质量**：AI配的图经常不搭——该换就换
4. **文字精简**：AI容易堆砌文字——每页控制在3-5个要点
5. **数据图表**：核对图表数据是否正确，标签是否清晰
6. **排版细节**：对齐、间距、字体一致性

## 四、各工具快速上手

### AiPPT (aippt.cn)

1. 打开网站，注册登录
2. 输入主题或粘贴文本/上传文档
3. 选择模板风格
4. AI生成大纲 → 确认或修改大纲
5. 生成完整PPT → 在线编辑调整
6. 导出 PPTX 或 PDF

**优点**：中文友好、速度快（1分钟出稿）、操作直观
**缺点**：模板设计感一般、导出的PPTX在PowerPoint中排版可能有偏差

### WPS AI

1. 打开WPS → 新建演示文稿
2. 点击「WPS AI」→ 输入主题
3. 选择场景和页数
4. AI生成初稿 → 直接在WPS中编辑
5. 保存为PPTX

**优点**：与WPS无缝衔接、原生PPTX、协作方便
**缺点**：AI功能较基础、模板风格偏常规

### 讯飞智文 (zw.xfyun.cn)

1. 打开网站，登录讯飞账号
2. 选择「创建文档」→ 输入主题
3. AI生成大纲 → 可编辑修改
4. 选择模板 → 生成PPT
5. 在线编辑 → 导出

**优点**：内容质量较高、逻辑清晰
**缺点**：设计模板有限、导出格式受限

### Gamma (gamma.app)

1. 打开 gamma.app，注册（支持Google登录）
2. 点击「New」→ 选择生成方式（主题/粘贴文本/导入文件）
3. 输入提示词（支持中文输入）
4. AI生成大纲 → 确认
5. 选择主题风格 → 生成完整演示
6. 在线编辑（拖拽调整、换模板、加元素）
7. 导出 PPTX / PDF / 分享链接

**优点**：设计感最强、实时协作好、交互体验流畅
**缺点**：免费版限制约10页、PPTX导出有排版损失、中文优化不足

### Canva AI

1. 打开 canva.com → 选择「演示文稿」
2. 使用「Magic Design」输入主题
3. AI生成多个设计方案 → 选择一个
4. 在Canva编辑器中精修（海量素材库）
5. 导出 PPTX / PDF / 图片

**优点**：设计素材最丰富、模板质量高
**缺点**：AI生成的内容逻辑较差、需要大量手动调整

### Microsoft Copilot (in PowerPoint)

1. 打开PowerPoint（需M365订阅）
2. 点击Copilot图标
3. 输入「创建一份关于[主题]的[10]页演示文稿」
4. Copilot生成初稿 → 在PowerPoint中直接编辑
5. 可用Copilot继续优化单页内容

**优点**：原生PPTX、无格式损失、与Office生态集成
**缺点**：需要M365订阅、设计模板有限

## 五、常见坑与避坑指南

### 内容类

| 坑 | 原因 | 解决方案 |
|----|------|---------|
| AI编造数据/引用 | LLM的幻觉问题 | 所有数据必须人工核实，不接受AI编的数字 |
| 内容空洞、套话多 | 提示词太模糊 | 给具体素材、限定每页要点数、指定内容深度 |
| 逻辑跳跃/章节混乱 | AI不理解你的领域逻辑 | 先自己写大纲，让AI基于大纲生成 |
| 术语使用错误 | AI对专业领域理解有限 | 生成后逐页检查术语，手动修正 |

### 设计类

| 坑 | 原因 | 解决方案 |
|----|------|---------|
| 导出PPTX排版错乱 | 工具间渲染引擎不同 | 导出后用PowerPoint/WPS重新检查排版 |
| 配图不搭/质量差 | AI配图匹配度有限 | 自己准备图片素材，手动替换 |
| 风格不统一 | 多次生成导致风格漂移 | 一次性生成，选定模板后不要频繁切换 |
| 文字太多太密 | AI倾向于堆砌文字 | 手动精简，每页控制在30字以内 |

### 流程类

| 坑 | 原因 | 解决方案 |
|----|------|---------|
| 反复生成浪费时间 | 想一次到位 | 先确认大纲再生成全文，大纲阶段多迭代 |
| 免费额度用完 | 不同工具额度不同 | 大纲阶段用免费工具，定稿后用付费工具出最终版 |
| 协作时版本混乱 | 多人编辑不同步 | 用支持实时协作的工具（Gamma/WPS），避免传文件 |

## 六、进阶技巧

### 1. 组合使用策略

```
内容生成：用 Kimi/ChatGPT 写好大纲和要点
    ↓
PPT生成：把大纲粘贴到 AiPPT / Gamma 生成视觉版
    ↓
精修打磨：导出PPTX，在PowerPoint/WPS中做最终调整
```

这比纯靠一个工具从头到尾效果好得多。

### 2. 文档转PPT的最佳实践

- 先把文档精简为大纲（去掉冗余文字）
- 明确标注章节结构（一/二/三 → 对应PPT分节）
- 数据单独列出（方便AI生成图表）
- 上传时选择"保留原文结构"选项（如果有）

### 3. 批量制作

- 先做一份标准模板PPT
- 用AI生成不同主题的内容
- 手动套用模板 → 批量产出

### 4. 演讲备注

部分工具（如讯飞智文）支持自动生成演讲备注。如果工具不支持：
- 把PPT内容粘贴给Kimi/ChatGPT
- 让它为每页生成2-3句演讲提示
- 复制到PPT的备注栏

## 八、评分说明

本文评分基于以下维度（10分制）：

- **内容质量**：AI生成内容的逻辑性、准确性、深度
- **设计美感**：模板质量、排版精致度、视觉一致性
- **中文支持**：中文输入输出质量、中文模板丰富度
- **上手容易**：学习成本、操作流程复杂度
- **免费额度**：免费功能的覆盖范围和使用限制
- **导出格式**：支持的导出格式、导出后格式保真度

> 注意：AI工具迭代很快，本文信息基于2026年中的状态，具体功能可能有变化。建议直接试用后再做决定。
