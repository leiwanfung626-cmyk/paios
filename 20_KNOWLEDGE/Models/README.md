# Models — Knowledge Base

> **Type**: Models
> **Lifecycle**: DRAFT
> **Version**: 1.0.0

## Purpose

This directory contains **Models**-typed knowledge assets.

## Structure

- `_index.md` — Index of all entries
- `_template.md` — Template for new entries
- Individual `.md` files — knowledge entries

## Rules

- Every entry must use the Front Matter template.
- Every entry must have a unique ID.
- Review lifecycle before marking as validated.
