# 项目清单 — QuarkSync 自动分类

> 在此列出你的项目名称，自动分类脚本支持两种识别方式：
> 1. 文件名以项目名开头
> 2. 文件名含项目关键词（推荐）
> 匹配则放入 `项目档案/项目名/` 文件夹。

## 如何添加

支持两种格式：

**简单格式**（仅前缀匹配）：
```markdown
- 项目名称
```

**扩展格式**（支持前缀+关键词匹配）：
```yaml
项目名称:
  folder: 项目名    # 对应的文件夹名（中文）
  keywords: [kw1, kw2]  # 可选：文件名含这些词也归入
```
